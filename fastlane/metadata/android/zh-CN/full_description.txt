为 Muzei 3 提供 Wallhaven.cc 壁纸来源，让每次轮播都换上一张新壁纸。

壁纸来源
* 排行榜：可选择最近 1 天到 1 年的时间范围
* 热门
* 最新
* 浏览量最高、收藏量最高
* 随机，可指定种子以便重复使用同一批排序

过滤条件
* 内容分级：SFW、Sketchy、NSFW。Sketchy 与 NSFW 需要到 Wallhaven 账号设置中取得免费的 API 密钥
* 分类：综合、动漫、人物
* 搜索关键词，支持 Wallhaven API 的完整查询语法
* 长宽比：横向、纵向、超宽屏 (21x9)、正方形
* 最低宽度与高度，或直接指定最低分辨率
* 主色调

运作方式
* 可自行设定每次刷新下载的壁纸数量，避免短时间内重复
* 已下载的壁纸会保存在本机，不会重复下载
* 可在应用内浏览已下载的壁纸，一次选取多张后删除或保存
* 可将壁纸保存到自己的存储位置，不受缓存清理影响
* 可选择每天定时清除缓存，也可随时强制刷新
* 可直接在 Muzei 中分享、查看详情或删除当前壁纸

隐私
* 不追踪、不统计、无广告
* 除了向 Wallhaven 发出的请求以外，不会向外部发送任何数据
* 若设置了 API 密钥，该密钥只会发送给 wallhaven.cc
